# Data Learning Examples

This directory contains small, self-contained examples used to learn the technologies required for the Car Auction Analyzer project.

These files are not part of the production backend. Their purpose is to understand each concept individually before integrating it into the main application.

## Learning Progression

### 1. Local CSV Processing
Learn how to:
- Read CSV files
- Inspect datasets
- Filter data
- Save new CSV files

### 2. External API Integration
Learn how to:
- Send HTTP requests
- Handle JSON responses
- Convert API data into pandas DataFrames
- Save API data

### 3. FastAPI CSV Service
Learn how to:
- Build REST endpoints
- Serve local CSV data
- Use Pydantic models
- Return JSON responses

### 4. FastAPI API Proxy
Learn how to:
- Connect to external APIs
- Process responses
- Expose your own API endpoints
- Prepare for backend integration

---

These examples serve as stepping stones toward the production implementation of the Car Auction Analyzer using:

- Spring Boot
- React
- PostgreSQL
- External vehicle data APIs
- Docker
